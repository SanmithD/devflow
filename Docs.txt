Using Cloudinary free tier is a very good choice for a resume/showcase AI SaaS.
 
It’s commonly used in:
 
Next.js apps
 
portfolios
 
AI SaaS projects
 
social/media apps
 
Official site:
Cloudinary
 
Best Architecture for Fast Uploads
DO NOT upload through your Next.js server

Bad flow:
Browser → Next.js API → Cloudinary
This is slower and wastes Vercel bandwidth.
 
Best Practice → Direct Uploads
Use:
Browser → Cloudinary directly
Then save returned URL into Prisma/PostgreSQL.
 
This is:
 
faster
 
scalable
 
cheaper
 
production standard
 
Recommended Setup
Frontend Upload
Use:
 
npm install next-cloudinary
Official package:
next-cloudinary
 
Fastest Upload Method
Use Upload Widget
Cloudinary provides:
 
drag/drop
 
compression
 
progress
 
retry
 
mobile optimization
 
Example:
 
<CldUploadWidget
  uploadPreset="your_preset"
  onSuccess={(result) => {
    console.log(result.info.secure_url);
  }}
>
  {({ open }) => (
    <button onClick={() => open()}>
      Upload
    </button>
  )}
</CldUploadWidget>
Make Uploads Fast
1. Compress Images Before Upload
Use:
 
npm install browser-image-compression
This massively improves speed.
 
Especially on mobile.
 
2. Limit File Size
For showcase project:
 
Media	Recommended Limit
Images	2–5 MB
Videos	20–50 MB
3. Use Auto Optimization
Cloudinary can automatically optimize delivery.
 
Example URL transformations:
 
f_auto,q_auto
Meaning:
 
best format automatically
 
smart compression automatically
 
This makes image delivery VERY fast.
 
Best Way to Display Images in Next.js
Use Cloudinary image component:
 
<CldImage
  width="800"
  height="600"
  src="uploaded-image"
  alt="image"
/>
Benefits:
 
lazy loading
 
optimization
 
CDN delivery
 
responsive sizing
 
Database Strategy
Store ONLY metadata in Prisma:
 
model Upload {
  id        String @id @default(cuid())
  url       String
  publicId  String
  createdAt DateTime @default(now())
}
Do NOT store files in PostgreSQL.
